# FlexDisplay Android receiver changelog

## 0.5.0 - release candidate

- Add a normal Android phone companion flavor that pauses when backgrounded.
- Add local Privacy Centre and default-off one-shot camera policy.
- Add foreground push-to-talk Assist, bounded speaker/chime playback, and
  cancellation on lock or pause.
- Add local charging-aware Dock Mode and Quick Settings tile.
- Add authenticated notification dismissal/action outcomes and battery,
  charging, health, temperature, voltage, current, and plug telemetry.
- Add an independent Android version contract and protected Forgejo signing,
  verification, draft-canary, checksum, and metadata publication workflow.

## 0.4.0

- Add Android receiver fleet controls for Echo Spot and Echo Show 5 kiosk
  receivers.
